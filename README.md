# 1. Descripción

Este proyecto realiza un análisis de anomalías de temperatura global utilizando Python.

Se utilizaron herramientas de análisis de datos y visualización para estudiar la evolución histórica de las temperaturas climáticas globales.

El trabajo fue desarrollado utilizando metodología Scrum, Git, GitHub y Jira para la organización y trazabilidad de tareas.

---

# 2. Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Google Colab
- Git
- GitHub
- Jira
